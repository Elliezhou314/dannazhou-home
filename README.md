# 周丹娜个人主页

线上地址：https://www.dannazhou.com/ （GitHub Pages + 自有域名，推送到 `main` 分支后一两分钟自动更新）

这个仓库只放个人主页。脑雾克星的网页版在另一个仓库 `elliezhou314.github.io` 里（地址 https://elliezhou314.github.io/naowu2/ ），两边互不影响，**不要把域名挂到那个仓库上**：那样会连带改掉脑雾克星的地址，手机上存的启动码和进度会丢。

纯静态页面，没有构建步骤；只有改了页面文字时需要重新生成一次字体（见下）。主页没有 JavaScript；两个作品页（`demo/platform/`、`demo/industry-map/`）共用一个几十行的轮播脚本 `js/player.js`，没有它页面照样能看（停在第一张）；两个作品页另共用一个更小的 `js/loop.js` 管录制画面（见下）。

## 经营平台作品页（`demo/platform/`）

线上地址 https://www.dannazhou.com/demo/platform/ ，主页作品区「经营一体化平台」下的「查看演示」链过去。

- **只有截图、录制画面和说明**：标题下面是「录制画面」区块，三段无声、无播放控件的循环画面上下排列：指挥舱（三维场景缓慢环绕）、条款推演（模拟指针把进度款比例旋钮从 80% 拧到 70%）、施工仿真（改了策略后点「运行仿真」，结果换成新策略的推演）；每段下方左边是名称、右边是「录制画面 · 非在线操作」。第一段 `preload="metadata"`，后两段 `preload="none"` 靠封面占位，`js/loop.js` 让每段只在滚到视口内时播放。再往下是 8 张平台截图的轮播，加逐张的文字说明。公开页面只能看、不能操作。
- **规矩：不要把平台前端代码放进本仓库。** 本仓库是公开仓库，平台的脚本、样式、三维模型、第三方库、数据文件一律不放；`demo/platform/` 下只允许 `index.html`、`img/` 里的截图和 `media/` 里的视频与图像文件（轮播与录制画面的脚本是仓库自己的 `js/player.js`、`js/loop.js`）。
- **截图怎么重新生成**：平台的可运行副本在工作副本 `E:\Claude工作区\平台演示版构建\`（不在本仓库、不入库，`web/` 是已换成虚构数据的前端）。在那里运行：

```
cd E:\Claude工作区\平台演示版构建
python -X utf8 tools/capture_showcase.py
```

  脚本自己在 `web/` 起本地静态服务（127.0.0.1、空闲端口，截完关掉），用无头浏览器按 1920×1080 截 8 个画面，等动画和数字滚动停下再截，加右下角水印（文字在 `tools/showcase_image.py` 的 `MARK`），导出两种宽度的 WebP 直接写进本仓库的 `demo/platform/img/`，原图 PNG 留在那边的 `dist/showcase-raw/`。指挥舱是自动环绕的三维画面，每次截到的视角会略有不同。截图前会隐藏平台里的「演示版」标识和数据新鲜度提示，不改平台代码。截完要逐张看一遍，并核对页面说明文字和截图对得上。
- **录制画面怎么来的、怎么重录**：不是实时录屏（本机无头浏览器是软件渲染，实时录会一卡一卡），而是逐帧录：同一个工作副本里的 `tools/record_loop.py` 在页面脚本运行前注入一个可控时钟（`tools/loop_clock.js`，接管 `performance.now`、`Date`、`requestAnimationFrame`、定时器和 CSS 动画），等场景加载、数字滚动跑完后接管时间，每次只前进 1/24 秒、渲染一帧、截一张图，所以帧距完全均匀。逐帧缩到 1280×720，加和截图一样的水印，然后在无头 Chromium 里用 WebCodecs 编成 VP9 并封装成 WebM（时间戳按帧号给定，不按真实时间），另出 960 宽、12 帧/秒的动态 WebP 和封面。录制时隐藏演示版标识、数据新鲜度提示和平台自带的操作提示字（如指挥舱右下角「拖拽转向 · 滚轮远近 · Esc 退出」、条款推演收起按钮上的 Esc 键帽），只在录制用的副本里加样式，不改平台代码。三段各自的做法：
  - **指挥舱**（`--scene cockpit`）：按 1920×1080 视口录。镜头用平台自己的运镜接口在「环域巡望」机位两侧缓慢摆过约 16°（4.5 秒），正放＋倒放拼成约 9 秒的循环，首尾速度都是 0，接缝看不出来。不加指针。
  - **条款推演**（`--scene terms`）：按 1440×810 视口录（卡片几乎占满画面，缩到 1280 宽后字不至于太小），背后三维停住巡航。模拟指针移到旋钮上 80% 的光点、按住，沿刻度圈拧到 70%，松手、移开；旋钮读数、垫资峰值、资金成本、利润和水位槽都是平台当场算出来的。
  - **施工仿真**（`--scene simulation`）：按 1920×1080 视口录。开头是「工期节奏改成赶工、对下过程付款比例改成 70%、还没点运行」的状态（下面仍是默认策略的结果），指针移到「运行仿真」点一下，指标和曲线换成新策略的结果。平台的运行是瞬间完成的，没有加载过程，所以点击后用约 0.4 秒交叉淡化衔接，不伪造进度条。
  - 后两段的循环方式是：开头停留约 0.8–1 秒 → 操作 → 结尾停留 → 最后 0.5 秒逐帧与首帧交叉淡化，不倒放（数字倒着跳很怪）。模拟指针（白色箭头、细深色描边、成片里约 18px，按下时一圈淡出的小圆）由 `tools/loop_cursor.py` 用 Pillow 画在成片上；录制时真鼠标逐帧移到同一位置、在同一帧真按下 / 松开，界面反应与指针对得上。轨迹和节奏在 `tools/loop_ops.py`。

  重录（三段分别跑，每段几分钟）：

```
cd E:\Claude工作区\平台演示版构建
python -X utf8 tools/record_loop.py --scene cockpit
python -X utf8 tools/record_loop.py --scene terms
python -X utf8 tools/record_loop.py --scene simulation
```

  默认直接写进本仓库的 `demo/platform/media/`；中间帧、日志（含相邻帧像素差的流畅度自检、首尾接缝差值、操作前后画面上的读数）放在那边的 `dist/loop-work/<场景名>/`。换一个场景只需在 `tools/loop_scenes.py` 或 `tools/loop_ops.py` 里加一项。录完要抽几帧看一遍，确认没有空白、报错提示、操作提示字和真实名称。
- **改说明文字**：直接改 `demo/platform/index.html`，改完重新生成字体（见下）。说明里只写截图里看得到的内容，不写具体数字。
- 截图里的项目、单位、人名、法院、案号都是虚构写法（项目1、示例业主单位甲、律师甲、示例一区人民法院等），金额与日期是虚构的验证数值。

## 改了页面文字之后

字体只保留了页面上出现过的字，新加的字会退回系统字体。改完任何页面（`index.html`、`404.html`、`demo/platform/index.html`、`demo/industry-map/index.html`）的文字后运行（脚本扫仓库里除谷歌验证文件以外的所有 html，连同图片 `alt` 等会显示出来的属性）：

```
python -X utf8 tools/subset_fonts.py
```

脚本读取 `tools/_src/` 下的字体源文件（不入库）。源文件缺了就从 Google Fonts 官方仓库 https://github.com/google/fonts/tree/main/ofl/ 重新下载，改名后放进 `tools/_src/`：

- `notoserifsc/NotoSerifSC[wght].ttf` → `NotoSerifSC-VF.ttf`
- `notosanssc/NotoSansSC[wght].ttf` → `NotoSansSC-VF.ttf`
- `jost/Jost[wght].ttf` → `Jost-VF.ttf`

需要 `pip install fonttools brotli`。
